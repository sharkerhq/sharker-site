# SHARKER Landing Page

Public landing page for the SHARKER design-partner program.

## Publish on GitHub Pages

1. Create a public repository, e.g. `sharker-site`.
2. Put these files in the repository root.
3. Public contact: `info@sharker.dev`; design-partner/pilot inquiries: `sales@sharker.dev`.
4. Push to `main`.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select **main** and **/(root)** and save.

No framework or build step is required.
